# DIKULT205 – Web Design II (University of Bergen, spring 2020)

Two assignments from DIKULT205 at the University of Bergen, part of my bachelor's degree in Digital Culture. Both were submitted in my exam portfolio in June 2020.

| Folder | Assignment | What it is |
|---|---|---|
| [`assignment5-the-rhetorics/`](assignment5-the-rhetorics/) | Assignment 5 – "The Rhetorics" | Two websites built around one news story, each designed to persuade a different audience (an early snapshot of the code), plus my rhetorical analysis of both sites. |
| [`assignment8-retrobaser/`](assignment8-retrobaser/) | Assignment 8 – "The Code Project" | Retrobaser, a PHP/MySQL community site for retro games, built with a partner. I was responsible for sign-up, login and the admin tools. |

Each folder has a README that explains the assignment, what I built and the choices I made.

## About the code

- This is the code as it was in 2020, written when I was learning PHP. I have not modernised it, so it shows where I was at the time.
- The sites ran on the university's teaching server (`turing.uib.no`). That server is gone, so there is no live demo.
- Database passwords have been removed. Assignment 8 includes `mysqli_connect.example.php` with placeholder values to show the connection setup.
- Logos and photos were used only in a course setting, as material for the rhetorical analysis.
