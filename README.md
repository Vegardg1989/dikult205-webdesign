# DIKULT205 – Web Design II (University of Bergen, spring 2020)

Two assignments from DIKULT205 at the University of Bergen, part of my bachelor's degree in Digital Culture. Both were submitted in my exam portfolio in June 2020.

| Folder | Assignment | What it is |
|---|---|---|
| [`assignment5-the-rhetorics/`](assignment5-the-rhetorics/) | Assignment 5 – "The Rhetorics" | Two websites built around one news story, each designed to persuade a different audience (an early snapshot of the code), plus my rhetorical analysis of both sites. Part of the code was lost; both worlds were restored in 2026. |
| [`assignment8-retrobaser/`](assignment8-retrobaser/) | Assignment 8 – "The Code Project" | Retrobaser, a PHP/MySQL community site for retro games, built with a partner. I was responsible for sign-up, login and the admin tools. |
| [`django/`](django/) | Both, rebuilt in 2026 | A Python/Django rewrite of both projects, running as live demos: [Retrobaser](https://www.vegardgundersen.com/demo/retrobaser/) · [The Rhetorics](https://www.vegardgundersen.com/demo/rhetorics/) |

Each folder has a README that explains the assignment, what I built and the choices I made.

## About the code

- Assignment 8 (Retrobaser) is the code as it was in 2020, written when I was learning PHP. I have not modernised it, so it shows where I was at the time.
- For assignment 5, parts of the original code are lost: only my rough draft from April 2020 survived. In 2026 I restored both worlds with help from Claude, Anthropic's AI assistant, from the screenshots in my exam portfolio and the Retrobaser login code. The [assignment 5 README](assignment5-the-rhetorics/README.md#restoration-2026) explains what was restored and what changed.
- The sites ran on the university's teaching server (`turing.uib.no`). That server is gone, so the live demos are the Django versions in [`django/`](django/).
- Database passwords have been removed. Assignment 8 includes `mysqli_connect.example.php` with placeholder values to show the connection setup.
- The sites are fictional and not affiliated with any organisation. In 2020, logos of real organisations were used only in a course setting, as material for the rhetorical analysis. The restored pages and the live demos use fictional logos instead.
